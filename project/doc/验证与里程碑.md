### 3.2 关键结论：横带根因

> 现象：首图即有条带，位置每次上电不同，同一次会话内稳定；双读版更重。

定位过程（结论保留，过程省略）：

1. **改约束/打拍/加保护都无效** → 不是时序问题；M0 带着 -6.167ns 违例也能干净显示；
2. **自检（独占总线写 307200 字再读回）几乎全对** → SDRAM 存储本身没问题；
3. **冻结显示读后，连续多次加载全干净** → 根因是**显示读与帧写入并发**时控制器丢写；
4. 128 拍 burst 间隔保护无效 → 不是“两个 burst 挨太近”，而是加密控制器内部的读写模式切换行为。

### 3.3 解决方案：开机只写、运行只读

```
上电：扫描 4 张 BMP → 依次写入 SDRAM 槽 0..3（各 307200 字）
      期间 display_valid=0，帧缓存读被门控 → 绝不并发
运行：K1/轮播只改 disp_buf_idx（2bit 槽号）
      读引擎在下一帧边界换基地址 → 瞬间切换、无撕裂
```

槽位：`BUF0=0 / BUF1=307200 / BUF2=614400 / BUF3=921600`（共 1.2M 字 < 2M 字）。

### 3.7 M1 补丁：闲置槽噪点（2026-10-25）

**现象**：静止单张图若干分钟后，切到其它槽会出现稀疏、固定位置的单像素彩色噪点；正在显示的槽始终干净。

**定位**：

| 实验 | 结果 |
|:--|:--|
| 自检（独占总线写 307200 字再读回） | 几乎全对 → 存储与写路径正常 |
| `SELF_REFRESH_INTERVAL` /4 | 略微延缓，未消除 |
| 关闭控制器自刷新（`self_refresh_open=0`） | 未消除 |
| 按 128 字步长“点读”全片（每帧一遍 / 消隐期循环） | **完全无效** |
| 显示中的槽（每帧顺序读满） | 始终干净 |

**结论**：这颗嵌入式 SDRAM 的自动刷新对闲置行不足，且**只有“顺序整段读”会被当作有效访问**；点读无效。

**解决**：`sdr_refresh_sweep` 在每帧消隐期顺序读 4 个槽：

- M1 实际窗口：`fb_read_finish`（`v_cnt≈524`）至 `vs` 下降沿（`v_cnt=9`）共 `V_FP=10` 行（`320µs ≈ 40k` 字/帧），跨帧连续推进，4 槽 ≈31 帧读完一轮（≈0.52s）；
- M2 交接时序：因 `v_active` 在 `v_cnt==44 && h_cnt==15` 置起，但该行有效像素期间 `v_cnt` 已递增为 45，距首个有效像素（`h_cnt≈160`）仅 `5.8µs`（不够读 A+B 两行 `10.24µs`），M2 首行 `y=0` 必须在 `v_cnt=44` 提前一整行（~`37.8µs`）预取；而最后一行 `y=479` 在第 478 行（`v_cnt=523`）内即取完，故 M2 真实交接链为：**`最后一行取完 → 启动扫描 → 到 v_cnt=44（或满 150k 字）停止发 en → 排空 12~16 拍（保持 active=1） → 行读取接管`**（空闲约 44 行 `1.4ms`，稳跑 150k 字/帧）；
- 读数据不写 `rfifo`，对显示无影响；
- 实测静止 15 分钟以上切图无噪点。

**代价**：LUT +89（3,905 → 3,994），消隐期占用总线，帧率/加载时间不变。

### 3.8 M2 行缓冲/转场（2026-10-25）

**实现**：`line_sched` + `frame_line_read` + 2×`line_buffer` + `mixer` + `disp_ctrl`；每行取 A/B 各 640 字，溶解/水平滑动，自动轮播 4s。

**上板问题 1：首行预取早了两行**
- `v_active` 在 `v_cnt==44` 置起，但有效像素期间 `v_cnt=45`；原调度在 43 预取，显示第 0 行时正在写第 2 行，读写同一 bank；
- 修正为 `v_cnt=44` 预取 y=0，`45..523` 取 y=1..479；
- `tb_chain` 增加“有效显示期间写 bank 不得等于读 bank”断言：修复前 240 万次冲突，修复后 0。

**上板问题 2：行内像素错位/纵向梳齿**
- `frame_line_read` 最初在 `Sdr_busy` 时暂停 `App_rd_en`，一行 1280 字被拆成不连续小段，控制器返回节奏变化导致行内像素错位；
- 改为像 M1 `frame_fifo_read` 一样连续发完整 1280 个读命令，撕裂消失。

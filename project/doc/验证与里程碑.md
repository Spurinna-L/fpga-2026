# 验证与里程碑 v3.1

> 原则：**M0 不通过，不碰扩展**。每个里程碑必须有"可演示 + 可复现"的验收。

---

## 1. 里程碑总览

| 阶段 | 目标 | 关键交付 | 验收 |
|:--|:--|:--|:--|
| **M0 基线复现** | 官方 `lab_ex5_i2s` 跑在我们板上 | 改引脚 + `edid=0` + 3 PLL + POR | 图片上屏 + HDMI 出声 + key1/key2 |
| **M1 基础达标** | 640×480 + 32bit 帧缓存 + 固化 | 4 端口 + `fb_writer` + `fb_mgr_dual` + QSPI | 基础 4 项全绿 |
| **M2 转场+字幕** | A/B 溶解 + 中文字幕 + 参数 | `swap_ctrl` + `transition` + 字库/OSD | ①②④ 可演示 |
| **M3 WAV+频谱** | TF WAV + 频谱柱 | `sd_arbiter`/`wav_read`/`pcm_player`/`audio_viz` | ③ 音频 + ⑤ 可视化 |

## 2. M0 基线复现

### 交付
- 清空并重构 `project/rtl/`（旧 RTL 归档到 `project/rtl_legacy/`），把官方 `lab_ex5_i2s` 的 RTL 搬入；
- 改引脚到我们板（HDMI `P1/N1/P4/J3`、SD `F15/F13/F14/D14`、键盘/数码管）；
- `I_edid_read_trig = 0`（本板无 DDC）；
- 3 个 PLL + `por_gen`；
- 先用官方 `frame_read_write` + `sdram` IP 跑通。

### 验收
- [ ] 显示器出现 640×480 图片；
- [ ] HDMI 出声（音阶测试音，需带喇叭的显示器/电视）；
- [ ] key1 切下一张、key2 开关自动轮播；
- [ ] 连续运行 10 分钟不花屏/不死机；
- [ ] 记录资源占用、时序余量、PLL 锁定。

### 失败排查
| 现象 | 优先检查 |
|:--|:--|
| 全黑 | PLL 锁定、`por_gen`、HDMI 核 `I_rst`、`EDID` 是否误触发 |
| 有图无声 | 显示器音频设置、I2S 时钟、`audio_valid`、ACR |
| 花屏/撕裂 | SDRAM 初始化、`rd/wr` 时钟、换帧点 |
| 读卡失败 | SPI 引脚、FAT32、卡容量/格式 |

- [ ] 无撕裂、无欠载；
- [ ] 4 张 BMP 扫描/轮播；
- [ ] 上电自启（拔掉下载器）；
- [ ] 基础 4 项全绿。

| 测试 | 方法 | 通过标准 |
|:--|:--|:--|
| 帧率 | 显示器菜单/示波器 | ≈59.5Hz |

- [ ] 亮度/对比度按键实时变化；

| 测试 | 方法 | 通过标准 |

| 溶解 | 连续切图 | α 平滑 0→255，无撕裂 |

| 字幕 | 长文本滚动 | 无闪烁、无错字 |

## 7. 调试指示

### 8 位 LED

| LED | 含义 |
|:--|:--|
| 0 | `sys_pll` lock |
| 1 | `video_pll` lock |
| 2 | `audio_pll` lock |
| 3 | SD 初始化完成 |
| 4 | 帧缓存就绪 |
| 5 | 当前 front（A/B） |
| 6 | 读欠载（锁存） |
| 7 | 转场进行中 |

### 数码管

| 位 | 含义 |
|:--|:--|
| 1 | `state_code`（SD 状态） |
| 2 | 媒体序号 |
| 3 | 转场 α 高 4 位 |
| 4 | 音频源（0=测试音，1=WAV） |

### 常见问题

| 现象 | 可能原因 |
|:--|:--|
| 半屏偏移 | 读口每帧 LOAD（必须只初始化一次） |
| 周期竖条纹 | 像素时钟不是 25MHz / 时序不对 |
| "闪烁" | 帧标记/α 每帧跳变；检查是否只在 V-BLANK 更新 |
| 左边框粗 | 显示器本身（静态测试图同样） |
| 无音频 | EDID 触发、I2S 时钟、`audio_valid`、显示器静音 |

## 8. 固化流程（QSPI）

1. TD 综合/布局布线，确认时序收敛；
2. 生成 `.bit`/`.bin`；
3. 用 TD Programmer 烧到 QSPI Flash（16MB）；
4. 断电、拔下载器、重新上电；
5. 确认自动加载、自动播放；
6. 记录固化版本号/日期。

> 单镜像要求：基础 + 扩展必须在**同一个 bitstream** 内，不能分次加载。

---

## 9. 长跑与现场

- 连续 2–4 小时轮播 + 切图 + 音频；
- 监控：LED 欠载、温度、电源；
- 现场演示脚本（3 分钟）：
  1. 上电 → 自动出图 + 音乐；
  2. key1 切图（看溶解）；
  3. key2 自动轮播；
  4. 调亮度/对比度（看 OSD 回显）；
  5. 展示频谱柱；
  6. 拔电重启，证明固化。

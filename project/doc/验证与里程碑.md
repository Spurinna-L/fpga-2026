## 6. M4 时序统一收敛 + QSPI 固化 + 烤机交付（11-01 ~ 11-04）

### 6.1 统一时序修复清单（消除现有 `-6.167ns` 与 `-0.698ns` 违例）
1. **跨时钟域复位同步化**：
   - 将 `por_done` 分别通过 2FF 同步器（`reset_sync`）同步到 `sd_card_clk (100M)`、`ext_mem_clk (125M)`、`video_clk (25M)`、`hdmi_5x_clk (125M)`、`audio_mclk (12.288M)`，消除 `clk (50M)` 组合逻辑直连各域寄存器的 `-3.7ns ~ -4.7ns` 违例；
2. **完善 `timing.sdc` 时序约束**：
   - 启用 `sd_card_clk`、`ext_mem_clk`、`video_clk`、`audio_mclk`、`clk` 之间的 `set_clock_groups -asynchronous`（跨时钟域数据均已由格雷码异步 FIFO 或 2FF 处理）；
   - 对 `ext_mem_clk` 与 `ext_mem_clk_sft`（SDRAM 外部/片内接口）补充合理路径约束；
3. **125MHz SDRAM 域内部组合逻辑打拍**：
   - 在 `frame_fifo_write.v` 中将 `into_burst` 的 21-bit 加法与比较结果寄存一拍，消除 `ext_mem_clk -> ext_mem_clk` 的 `-0.698ns` 建立时间违例。

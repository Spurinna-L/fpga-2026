## 1. 合并后的 `project/` 目标目录结构

```
project/
├── rtl/
│   ├── top_tf_hdmi_audio.v                # 顶层（合并自 base，集成全部扩展模块）
│   ├── SD/                                # 存储、BMP 解码与一写双读帧缓存
│   │   ├── sd_card_top.v                  # ✅ SPI 物理层顶层
│   │   ├── spi_master.v                   # ✅ SPI 字节收发
│   │   ├── sd_card_cmd.v                  # ✅ SD 命令状态机
│   │   ├── sd_card_sec_read_write.v       # ✅ SD 扇区读写
│   │   ├── bmp_read.v                     # ✅ 扇区扫描 BM 头 + 24-bit 像素提取
│   │   ├── sd_card_bmp.v                  # ✅ 4 图扫描/轮播/写握手 + 导出 img_idx
│   │   ├── frame_read_write.v             # 🟡 扩展为一写双读（wfifo + rfifo_a + rfifo_b）
│   │   ├── frame_fifo_write.v             # ✅ 含 WRITE_V_FLIP=1（M4 加 1 拍流水）
│   │   ├── frame_fifo_read.v              # ✅ 突发预取（例化 A/B 两路）
│   │   ├── sdram.v                        # ✅ 片内 8MB SDRAM 封装
│   │   ├── video_timing_data.v            # ✅ 640×480@60 时序与 read_req
│   │   ├── color_bar.v                    # ✅ 时序发生器内核
│   │   ├── video_delay.v                  # 🟡 扩展为同时对齐 rd_data_a/b 并输出 x/y
│   │   └── video_define.v                 # ✅ 定义 VIDEO_640_480
│   ├── include/                           # 官方 SDRAM 加密核
│   │   ├── global_def.v                   # ✅ 32-bit / 21-bit 地址定义
│   │   ├── sdr_as_ram.enc.v               # 🔒 加密核（黑盒）
│   │   ├── sdr_init_ref.enc.v             # 🔒 加密核（黑盒）
│   │   └── sdr_wrrd.enc.v                 # 🔒 加密核（黑盒）
│   ├── video/                             # 24-bit RGB888 视频处理与 OSD 合成
│   │   ├── test_pattern_640x480.v         # ✅ 无图彩条回退
│   │   ├── swap_ctrl.v                    # 🟡 A/B 转场状态与 alpha 斜坡生成
│   │   ├── transition.v                   # 🟡 升级为 24-bit RGB888（交叉溶解 + 水平滑动）
│   │   ├── video_proc.v                   # 🟡 升级为 24-bit RGB888（亮度/对比度，修复 2 拍对齐）
│   │   ├── osd_composer.v                 # 🟡 多图层合成（中文字幕+安路Logo+时间戳+参数+声波/频谱）
│   │   ├── font_rom_cn.v                  # 🟡 64 字 16×16 中文字库 ROM（2KB）
│   │   ├── font_rom_ascii.v               # 🟡 8×16 ASCII 字库 ROM
│   │   ├── logo_rom.v                     # 🟡 安路科技 ANLOGIC Logo 位图 ROM
│   │   └── video_rgb_to_axis_640x480.v    # ✅ RGB888/DE/VS → AXIS
│   ├── audio/                             # 板载音频合成、ACR 与可视化
│   │   ├── hdmi_audio_tone_i2s_64fs.v     # ✅ L1 音阶测试音
│   │   ├── synth_player.v                 # ⚪ L2 多谐波/双音伴奏波表合成器
│   │   ├── audio_mux.v                    # ⚪ L1 / L2 音源切换
│   │   ├── I2S_receiver.v                 # ✅ I2S → 24-bit PCM
│   │   ├── audio_arc_calculate.v          # ✅ ACR N=6144，动态 CTS
│   │   └── audio_viz.v                    # ⚪ 640×8bit 实时声波曲线 RAM + 8 段频谱能量柱
│   ├── hdmi/                              # HDMI 1.4b 协议核与 PHY
│   │   ├── hdmi_1_4b_transmitter_core_wrapper.enc.v # 🔒 官方 HDMI 1.4b 加密核
│   │   ├── hdmi_phy_warpper.v             # ✅ 4 通道 TMDS PHY 封装
│   │   └── lane_lvds_10_1.v               # ✅ 10:1 ODDR 串行化
│   ├── control/                           # 矩阵键盘、寄存器与数码管
│   │   ├── keyboard_scan.v                # ✅ 4×4 矩阵键盘行扫描
│   │   ├── key_filter.v                   # ✅ 20ms 消抖
│   │   ├── regs.v                         # 🟡 16 键事件译码、参数寄存器、1Hz 时间戳计数
│   │   ├── seg_led.v                      # ✅ 4 位数码管动态扫描
│   │   ├── seg_led_decoder.v              # ✅ 七段译码
│   │   └── seg_sel_decoder.v              # ✅ 位选译码
│   └── ip/                                # PLL 与异步 FIFO IP
│       ├── sys_pll.v / .ipc               # ✅ 100M / 125M / 125M_180
│       ├── video_pll.v / .ipc             # ✅ 25M / 125M
│       ├── PLL_HDMI_AUDIO.v / .ipc        # ✅ 12.288M
│       ├── afifo_16_32_256.v / .ipc       # ✅ wfifo_32_32_512（纯 Verilog + BRAM 推断）
│       └── afifo_32_16_256.v / .ipc       # ✅ rfifo_32_32_512（纯 Verilog + BRAM 推断）
├── constraints/
│   ├── pin.adc                            # ✅ 板卡引脚约束
│   └── timing.sdc                         # 🟡 时钟约束（M4 完善异步组与复位伪路径）
├── doc/                                   # 全套设计文档
├── main_project.al                        # TD 主工程
└── README.md
```

## 1. 目录结构

```
project/src/
├── td_project/
│   ├── main_project.al                # TD 主工程（顶层 top）
│   └── al_ip/PLL_HDMI_AUDIO.*         # 12.288MHz 音频 PLL
├── user_source/
│   ├── hdl_source/
│   │   ├── top_tf_hdmi_audio.v        # 顶层
│   │   ├── SD/                        # SD/BMP/帧缓存/SDRAM/视频时序
│   │   ├── include/                   # global_def + SDRAM 加密核（位置固定）
│   │   ├── video/                     # 行读取/行缓冲/混合/亮度/OSD/Logo/AXIS
│   │   ├── audio/                     # L1 测试音、I2S、ACR
│   │   ├── hdmi/                      # HDMI 1.4b 加密核 + PHY
│   │   ├── control/                   # 键盘/regs/数码管/复位
│   │   └── ip/                        # PLL / 异步 FIFO（TD IP）
│   └── constraints_source/
│       ├── pin.adc
│       └── timing.sdc
├── sim/                               # 语法检查 + 全部 M0–M2 testbench（fail-fast）
└── tools/                             # BMP 生成/检查
```

> **路径约束**：`SD/sdram.v` 与 `include/sdr_*.enc.v` 内部用相对路径 `../user_source/hdl_source/include/global_def.v`，`td_project/` 必须与 `user_source/` 同级。

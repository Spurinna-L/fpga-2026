## 4. 实施顺序（依赖）

```
M0  官方基线
    PLL → por_gen → sd_card_top → bmp_read → sd_card_bmp
    → frame_read_write（临时）→ HDMI 核/PHY → 出图 + 出声

M1  帧缓存替换
    sdram_ctrl_wrap(32bit) → fb_writer → fb_mgr_dual（单读）
    → video_timing_640x480 → transition（旁路）→ axis → HDMI

M2  A/B + OSD
    swap_ctrl → fb_mgr_dual（双读）→ transition（α）
    → text_layer/font_rom_cn → osd_layer → video_proc

M3  WAV + 频谱
    sd_arbiter → wav_read → wav_to_pcm → audio_bram
    → pcm_player → audio_mux → audio_viz → media_sched

M4  缩放（可选）+ 固化 + 烤机
```

## 6. 备注

- 官方 `sd_card_bmp` 只做**最小改动**：
  1. `sd_sec_read*` 改为 `sd_arbiter` 客户端；
  2. `disp_buf_idx` 由 `swap_ctrl.front` 驱动；
  3. 新增 `frame_ready`/`back_free` 握手；
  4. 不动 FAT32/BMP/扫描/轮播逻辑。
- 官方 `frame_read_write`/`sdram` IP 不再使用；保留作回退。
- 加密 IP 只黑盒例化，不改 `.enc.v`。

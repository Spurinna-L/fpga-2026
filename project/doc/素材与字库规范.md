# 素材与字库规范 v3.1

> 目标：让"素材制作 → TF 卡 → 板子"这条链**可重复、可复现**，避免"电脑上好好的、板子上花屏/读不出"。

---

## 1. BMP 图片

### 1.1 格式要求（硬性）

| 项 | 要求 |
|:--|:--|
| 格式 | **BMP**（真正的 BMP，不能把 PNG/JPG 改后缀） |
| 分辨率 | **640 × 480** |
| 色深 | **24-bit RGB**（无调色板） |
| 压缩 | **非压缩**（BI_RGB） |
| 行序 | 自底向上（bottom-up）或自顶向下（top-down）均可，工程用 `WRITE_V_FLIP` 纠正 |
| 行对齐 | 每行 4 字节对齐（640×3=1920，已对齐） |
| 文件大小 | 约 921,654 字节（640×480×3 + 54 头） |

### 1.2 命名

```
01.bmp  02.bmp  03.bmp  04.bmp
```

- 根目录，最多 **4 张**（官方 `sd_card_bmp` 扫描上限）；
- 按文件名/扇区顺序轮播；
- 建议只放需要演示的图片，避免扫描到旧文件。

### 1.3 转换工具

官方提供：

```
lab_ex5_i2s/doc/convert/convert_images_to_bmp.py   # 任意图片 → 640×480 24bit BMP
lab_ex5_i2s/doc/convert/sync_to_sd.py             # 安全同步到 TF 卡（清理旧扇区）
```

用法见 `doc/convert/README.md`。

> ⚠️ 直接在电脑上删除旧图片，底层扇区可能残留旧数据，导致 FPGA 读到旧图/死锁。
> **必须用 `sync_to_sd.py` 或先格式化 TF 卡。**

## 2. WAV 音频（最终目标）

### 2.1 格式要求

| 项 | 要求 |
|:--|:--|
| 容器 | WAV（RIFF） |
| 编码 | PCM（无压缩） |
| 采样率 | **48kHz** |
| 位深 | **16-bit**（推荐）或 24-bit |
| 声道 | 立体声（推荐）或单声道 |
| 时长 | 建议 10–60s/首 |

### 2.2 命名与绑定

```
01.bmp ↔ 01.wav
02.bmp ↔ 02.wav
03.bmp ↔ 03.wav
04.bmp ↔ 04.wav
```

- 换图时 `media_sched` 切到同名 WAV；
- 没有同名 WAV 时，回退到测试音或静音；
- 单曲 BGM 循环也可（`media_sched` 不切曲）。

### 2.3 工具

```bash
ffmpeg -i input.mp3 -ar 48000 -ac 2 -sample_fmt s16 01.wav
```

- 确认 `ffprobe` 显示 `pcm_s16le, 48000 Hz, stereo`；
- 不要用 MP3 改后缀。

## 3. 中文字库

### 3.1 规格

| 项 | 值 |
|:--|:--|
| 点阵 | **16 × 16** |
| 每字 | 32 字节（16 行 × 2 字节） |
| 字数 | **512 个常用汉字** |
| 附加 | ASCII 8×16（数字/字母/符号） |
| 存储 | ERAM（16KB） |
| 取模 | 横向取模、高位在前（与 `text_layer` 约定一致） |

### 3.2 生成流程

1. 在 `doc/tools/font_chars.txt` 写入演示文案用到的所有汉字（去重）；
2. 运行：

```bash
python doc/tools/gen_font_mif.py \
  --font "C:/Windows/Fonts/msyh.ttc" \
  --chars doc/tools/font_chars.txt \
  --out rtl/video/font_rom_cn.mif \
  --size 16
```

3. 生成的 MIF 规格：**WIDTH=16，DEPTH=8192**（512 字 × 16 行），即 16bit × 8192 = 128Kb = **16KB**；
4. 在 TD 中用 `Mif_Maker`/IP Generator 生成 `font_rom_cn`（16bit × 8192，单端口 ROM）；
5. 同时生成 `font_rom_cn.map.txt`（`index<TAB>字符`），供 `text_layer` 查表；
6. 综合后确认 ERAM 占用 ≤ 16KB。

> 脚本已在本机用 `msyh.ttc` 跑通：75 个演示字 → 16bit×8192 MIF（105KB 文本）。

### 3.3 字符集建议

- 标语：欢迎光临 / 智能展陈 / 数字标牌 / 安路科技 / 新品上市 / 敬请期待
- 状态：正在播放 / 暂停 / 音量 / 亮度 / 对比度 / 自动轮播
- 数字：0–9、`:`、`.`、`/`、`%`
- 英文：A–Z、a–z（ASCII 8×16）

> 512 字足够覆盖固定文案；**不支持任意输入中文**（全 GB2312 需 216KB，ERAM 放不下）。

## 4. TF 卡

| 项 | 要求 |
|:--|:--|
| 容量 | 4–32GB（FAT32） |
| 格式 | **FAT32**（非 exFAT/NTFS） |
| 目录 | 根目录 |
| 文件 | `01.bmp`…`04.bmp`，`01.wav`…`04.wav` |
| 簇大小 | 默认即可 |

### 制作步骤

1. 用 `sync_to_sd.py` 或格式化；
2. 复制 BMP/WAV 到根目录；
3. 安全弹出；
4. 插到板子，上电。

| `convert_images_to_bmp.py` | 图片 → 640×480 24bit BMP | 官方 `doc/convert` |

## 6. 检查清单（上板前）

- [ ] BMP 是真正的 24bit 非压缩、640×480；
- [ ] WAV 是 PCM、48kHz、16bit；
- [ ] TF 卡 FAT32、根目录、≤4 张图；
- [ ] 文件名与配对正确（01↔01）；
- [ ] 字库字符覆盖全部文案；
- [ ] 没有旧图残留（已用 `sync_to_sd.py`）；
- [ ] 上电后数码管状态码正常。

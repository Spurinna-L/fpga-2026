## 2. 已废弃/被取代

| 旧决策 | 新决策 | 原因 |
|:--|:--|:--|
| 720p60 + 74.25/371.25MHz | 640×480 + 25/125MHz | 赛题基线 + PHY 风险 |
| DVI IP + PWM 音频 | HDMI 1.4b 核 + HDMI 音频 | 旧 IP 是 DVI，无数据岛；新官方核支持音频 |
| 自研 `fat32_reader`/`bmp_decoder` | 官方 `SD/` | 官方已给明文，省时省风险 |
| 自研 `fb_mgr`（16bit） | `fb_mgr_dual`（32bit） | A/B 双读 + RGB888 |
| 官方 `frame_read_write` | 4 端口 `sdram_ctrl_wrap` | 单读口无法做交叉溶解 |
| 淡出到黑转场 | A/B 交叉溶解 | 用户决策 |
| ASCII 字幕 | 中文 512 字子集 | 用户决策 |
| 缩放（任意→720p） | 暂不做 | 先保基础 |
| 音频走 SDRAM 环形缓冲 | 音频走 ERAM FIFO + SD 分时 | 4 端口全给图像；音频量小 |
| 麦克风现场频谱 | 播放 PCM 频谱 | 省资源/调试 |

## 2. 已废弃方案对照表

| 废弃方案 | 现行方案（v3.3） | 废弃原因 |
|:--|:--|:--|
| 旧 `Sdram_Control_4Port`（`sdram_ctrl_wrap`）+ `fb_writer`/`fb_mgr_dual` | **复用 `frame_read_write` 扩展为 1 写 2 读 + `sdr_as_ram`** | 旧 4 端口控制器硬编码 16-bit 且不支持 BMP `WRITE_V_FLIP` 逐行倒序写；复用 `frame_read_write` 更省资源且零风险 |
| 旧 `project/rtl` 下的 720p + 16-bit RGB565 + DVI 骨架 | **`base` 的 640×480 + 24-bit RGB888 + HDMI 1.4b 架构** | 旧工程无音频、分辨率与色深不符，已弃用 |
| 单音纯正弦波 L2 + 单纯 16 段 Goertzel 频谱 | **多谐波/双音伴奏 L2 + 实时声波曲线 + 8 段频谱柱** | 单音正弦波同一时刻仅 1 根频谱柱亮；加泛音/伴奏与实时声波曲线后视觉效果大幅提升且省 DSP |
| 仅静态标语 OSD | **64 字中文滚动标语 + 安路 Logo + 时间戳 + 参数回显** | 补齐赛题解析 PPT 中的全部得分要素 |

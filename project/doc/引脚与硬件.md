## 1. 引脚表

### 1.1 时钟 / 复位

| 信号 | 引脚 | 说明 |
|:--|:--|:--|
| `clk_50m` | **R7** | 50MHz 有源晶振 |
| `rst_n` | **A9** | SW0（低有效复位） |

### 1.2 HDMI（LVDS33）

| 信号 | 引脚 |
|:--|:--|
| `hdmi_clk_p` | **P1** |
| `hdmi_d0_p` | **N1** |
| `hdmi_d1_p` | **P4** |
| `hdmi_d2_p` | **J3** |

> `_N` 为相邻差分对，由 TD 自动分配。
> **本板 HDMI 没有 DDC/EDID 引脚**（原理图只引出 4 对 TMDS + 5V）→ `I_edid_read_trig = 0`。

### 1.3 TF 卡（SPI）

| 信号 | 引脚 |
|:--|:--|
| `sd_ncs` | **F13** |
| `sd_dclk` | **F15** |
| `sd_mosi` | **F14** |
| `sd_miso` | **D14** |

### 1.4 4×4 矩阵键盘

| 信号 | 引脚 |
|:--|:--|
| `kb_row[0..3]` | **D9 / F9 / C10 / E10** |
| `kb_col[0..3]` | **E11 / D11 / C11 / F10** |

### 1.5 数码管

| 信号 | 引脚 |
|:--|:--|
| `seg_sel[0..3]` | **C9 / B6 / A5 / A3** |
| `seg_led[0..7]` | **A4 / A6 / B8 / E8 / A7 / B5 / A8 / C8** |

### 1.6 LED（与 R-2R 复用）

| 信号 | 引脚 |
|:--|:--|
| `led[0..7]` | **B14 / B15 / B16 / C15 / C16 / E13 / E16 / F16** |

> 这 8 个引脚与板载 R-2R DAC 复用。本方案不用 R-2R，全部做 LED 状态灯。

### 1.7 音频备份

| 信号 | 引脚 |
|:--|:--|
| `audio_pwm` | **F3** → 低通 + FM8002A 功放 → 3.5mm/喇叭 |

> 主线音频走 HDMI；PWM 仅作备份/现场扩声。

## 2. 板卡注意事项

| 项 | 说明 |
|:--|:--|
| 片内 SDRAM | `EG_PHY_SDRAM_2M_32`（2M×32=8MB），**不占外部引脚** |
| HDMI DDC | **未引出**，不能读 EDID；HDMI 核 `I_edid_read_trig=0` |
| HDMI 口 | 本板只有 1 个 HDMI（TMDS 4 对） |
| LED/R-2R | 同一组 8 个 IO，二选一 |
| 键盘 | 4×4 矩阵，需行扫描 + 消抖 |
| 拨码 | SW0–SW7；本方案 SW0 作复位 |
| 调试器 | 板载 USB Cable / CH341；不影响数据通路 |

## 3. PLL 配置

### 3.1 `sys_pll`（50MHz 输入）

| 输出 | 频率 | 用途 |
|:--|:--|:--|
| C0 | 100MHz | SD/FAT32/BMP/WAV |
| C1 | 125MHz | SDRAM 控制器 |
| C2 | 125MHz 180° | SDRAM 相位 |

### 3.2 `video_pll`（50MHz 输入）

| 输出 | 频率 | 用途 |
|:--|:--|:--|
| C0 | 25MHz | 像素时钟 |
| C1 | 125MHz | TMDS 串行（5×） |

### 3.3 `PLL_HDMI_AUDIO`（50MHz 输入）

| 输出 | 频率 | 用途 |
|:--|:--|:--|
| C2 | 12.288MHz | 48kHz 音频主时钟（/256） |

> 三个 PLL 的 `lock` 都进 `por_gen`；全部锁定 + 计数后才释放复位。

---

## 4. 时序约束

- `pix_clk` 25MHz：视频流水线；
- `ser_clk` 125MHz：HDMI PHY；
- `sd_clk` 100MHz：SD；
- `mem_clk` 125MHz：SDRAM；
- 跨域路径用 `set_false_path`/`set_max_delay`（按 TD 实际报告补）；
- HDMI 输出引脚给 `LVDS33`，不要加 `PULLTYPE`。

---

## 5. 固化 / 上电

1. TD 生成 bitstream；
2. Programmer 烧 QSPI Flash（16MB）；
3. 断电、拔下载器、重新上电；
4. 确认自动加载、自动播放；
5. 记录版本/日期。

---

## 6. 上板前检查

- [ ] 引脚约束与 `top.v` 端口名一致；
- [ ] HDMI 差分对 `LVDS33`；
- [ ] SD 卡座引脚无互换（MOSI/MISO）；
- [ ] 键盘行列无短路；
- [ ] 3 个 PLL 锁定（LED0/1/2）；
- [ ] `por_gen` 释放复位；
- [ ] 数码管状态码正常；
- [ ] 固化后拔下载器仍能启动。

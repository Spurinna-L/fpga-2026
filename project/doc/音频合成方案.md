# 音频合成与可视化方案 v3.4（L1 测试音 / L2 多谐波合成 / 声波+频谱可视化）

> 决策：**音频主线采用"板载实时合成"**（L1 音阶测试音 + **L2 多谐波/双音伴奏波表合成**），不依赖 SD 卡音频文件；
> 可视化主线采用**"实时动态声波示波器曲线（Waveform）+ 8 段频谱能量柱（Spectrum Bars）"**同屏叠加。

---

> **当前状态（M3 已实现，待上板复测）**：L2 `synth_player`、`wave_capture`、`spectrum_analyzer`、`audio_viz` 已全部落地并通过 TD 综合/布局/布线/bitgen（0 error，Setup +0.541ns / Hold +0.019ns）。L1 音阶测试音保留，K9 一键切换。
> 音频链与存储调度解耦：不依赖 SD 卡，也不受“运行期只读”约束。

## 1. 为什么采用“多谐波/双音波表合成 + 声波/频谱双可视化”

| 考量点 | 设计原因与优势 |
|:--|:--|
| **满足赛题基础要求③** | 48kHz 采样率、ACR (N=6144) 动态时钟恢复，保留 L1 测试音可一键切回验证 |
| **解决单音合成频谱单调问题** | 纯单音正弦波在同一时刻仅含单一基频，频谱柱仅 1 根亮；改为**“主旋律 + 低音伴奏 + 基波/2次/3次泛音波表”**后，高中低频段同时具有丰富能量，8 段频谱柱律动饱满 |
| **命中赛题扩展⑤“频谱或波形显示”** | 赛题解析明确提出“生成频谱或波形显示”；增加 **640 点实时示波器声波曲线**仅耗 1 块 BRAM9K、**0 DSP**，却能呈现高帧率丝滑声波，与 8 段频谱柱形成极强的视觉冲击力 |
| **极低资源与零 SD 冲突** | 无需 SD 卡仲裁与大体量音频 FIFO，总计仅需 ~1,100 LUT + 2 块 BRAM9K + ~8 个 DSP |

## 2. L2：多谐波/双音伴奏波表音乐合成（`synth_player`）

### 2.1 架构框图（M3 实际实现）

```
note_step (32 音循环 + 贝斯根音)
   ├── 主声部 (Melody)：note_inc_m ──► phase_acc_m (32bit) ──► 64 项四分之一正弦表 + 象限镜像 ──► 音色整形 ──► 包络 ──┐
   └── 伴奏声部 (Bass) ：note_inc_b ──► phase_acc_b (32bit) ──► 同波表，低八度根音           ──► 伴奏包络 ──┼──► 相加限幅 ──► 24-bit PCM
                                                                                                        │
                                                                                        音色选择 (I_timbre[1:0])
```

### 2.2 核心参数与多音色设计（M3 实际实现）

| 参数项 | 规格说明 | 实现位置 |
|:--|:--|:--|
| 采样率与时钟 | `48kHz`（`12.288MHz` 主时钟 `/256` 严格分频） | `synth_player` 内 `cnt==255` 产生采样节拍 |
| 声部结构 | **2 声部**：旋律（32 音循环，C4–B4 十二平均律）+ 贝斯（低八度根音） | `note_idx` 步进 + `step_cnt` |
| 波表 | **64 项 8bit 四分之一正弦**（0,3,6,...,127）+ 象限镜像，LUT 组合 ROM、**0 BRAM**；全模块仅 1 个 DSP | `sin_q` 常量表 |
| 多音色切换（K10） | `timbre=0` 纯净正弦<br>`timbre=1` 近似方波（奇次谐波，Chiptune 风格）<br>`timbre=2` 近似三角/锯齿 | `I_timbre[1:0]` |
| 包络 | 每音 **48 样本**淡入淡出，消除音符切换爆音（Click/Pop） | `env_cnt` |
| 曲目长度 | 32 音循环乐段 | `note_idx[4:0]` |

> 原方案中的 256×16 多谐波波表与 ADSR 已被更省资源的「四分之一正弦表 + 象限镜像 + 音色整形 + 短包络」替代，听感相近但省掉 1 块 BRAM 与多个乘法器。

### 2.3 相位累加频率字计算

$$
\text{freq\_word} = \text{round}\left(\frac{f_{\text{note}} \times 2^{32}}{48000}\right)
$$

例如标准音 `A4 = 440Hz` $\rightarrow$ `freq_word = 39,370,534`。

## 3. 实时声波曲线 + 8 段频谱能量柱（`audio_viz`）

### 3.1 实时示波器声波曲线（Waveform）—— 零 DSP、高丝滑度
1. **双口行缓存（`wave_capture`：`640 × 8bit`，1 块 BRAM9K）**：
   - **写侧（48kHz 采样节拍）**：过零（负→正）触发写入 + 640 样本最小间隔锁相，把 24bit 有符号样本取高 8 位并限幅到 `±16`，作为相对基线的偏移写入 `wr_x`（`0..639`）；
   - **读侧（25MHz `video_clk`）**：`audio_viz` 用 `d1_x`（比 `I_rgb` 提前 1 拍）作为读地址，BRAM 1 拍读出数据恰好与 `I_rgb` 同拍，`O_rgb` 保持**纯组合叠加**；`vs` 下降沿锁存读基准，并做越界保护；
2. **渲染逻辑与纵向避让**：
   - 全部图形收进 **右侧竖带 `x = 480 .. 639`（宽 160px）**，左侧 480px 主画面完全不参与叠加；竖带顶端从 `y = 72` 起，避开右上参数面板（`x = 472..631`、`y = 8..59`）、左上 Logo（`x = 8..39`、`y = 8..39`）与底部滚动字幕（`y = 444..467`）；
   - 波形带 **`y = 72 .. 184`（基线 `Y_WAVE_BASE = 128`，限幅 `±56px`）**，`y = 72` 起为避开参数面板留 12px 空隙；
   - 读地址由屏幕坐标换算：`wx_off = x - 480`、`wave_raddr = wx_off × 4`（640 点缓冲做 **4:1 抽取**，一屏约 3.5 个周期，等效采样率 12kHz，6kHz 以下无混叠）；
   - 扫描行命中 `y == Y_BASE - wave_off` 时渲染青色波形线（`24'h00FFFF`），并在其下方画 10 行渐变阴影（近端 3px 更亮）增强立体感。

### 3.2 8 段频谱能量柱（8-Band Spectrum Bars）
1. **频段划分**：`119Hz ~ 2596Hz`，由 9 级一阶低通的相邻差分切出 8 段；
2. **能量提取 `spectrum_analyzer`**：
   - 9 路低通**并联**对同一输入 `x18`，每路内部再**级联 3 级**（`a → b → c`，同下标）：`aN <= aN + Σ(dN >> k)`、`bN <= bN + Σ((aN-bN) >> k)`、`cN <= cN + Σ((bN-cN) >> k)`，系数 `k = 4,6,9,13,20,28,41,60,87` 全部用移位加法实现，**0 乘法器**；
   - 相邻低通输出相减得带通 → 取绝对值 → `>>4` 得 14bit 幅度 → 帧内累加 → `energy = acc >> 9`；
   - **级联而不是跨频段串接**：相邻频段之间必须并联（曾误写成 `dN = lp(N-1) - lpN` 的跨频段串接，高频被逐级压低，1kHz 单音只有第 0 段有值）；但**同一路低通自己串联 3 级**可以把裙边从 −20dB/dec 压到 **−60dB/dec**，频段间串扰大幅下降，柱形才会随音高整体移动（实测 440Hz 正弦的峰值段由第 3 段移到第 5 段、1kHz 由第 5 段移到第 6 段）；
3. **视觉平滑处理**：
   - 柱体高度在 `vs` 边界按 `bar <= (bar*3 + tgt + 2) >> 2` 更新（实现为 `bar*4 - bar`，无乘法器）；
   - 顶部白色峰值线保持历史最大值，之后每 2 帧降 1px；
   - **自动增益**：`gmax < 34` 时 `attn` 递减、`gmax > 44` 时递增（`attn` 4bit，初值 6），使 L1 音阶（±2e6）与 L2 合成器（幅度较小）都能撑满柱高；
   - 柱体颜色随高度渐变：底部翠绿（`24'h00E676`，`y = 435..371`）→ 中部明黄（`24'hFFEA00`，`y = 371..307`）→ 顶部火红（`24'hFF1744`，`y = 307` 以上）；
   - 版面：右侧竖带内 `x = 496..623`（8 根 × 16px 单元，柱宽 14 / 间隙 2，左右各留 16px），柱底 `y = 435`（距底部字幕 8px），柱高 = 段值 ×4 → `0..192px`（`y = 435..243`），与上方波形带（`y ≤ 184`）留 59px 空隙。

# 音频合成与可视化方案 v3.4（L1 测试音 / L2 多谐波合成 / 声波+频谱可视化）

> 决策：**音频主线采用"板载实时合成"**（L1 音阶测试音 + **L2 多谐波/双音伴奏波表合成**），不依赖 SD 卡音频文件；
> 可视化主线采用**"实时动态声波示波器曲线（Waveform）+ 8 段频谱能量柱（Spectrum Bars）"**同屏叠加。

---

> **当前状态（M1）**：L1 音阶测试音已上板；L2 合成与可视化属于 M3，本文描述目标方案。
> 音频链与存储调度解耦：不依赖 SD 卡，也不受“运行期只读”约束。

## 1. 为什么采用“多谐波/双音波表合成 + 声波/频谱双可视化”

| 考量点 | 设计原因与优势 |
|:--|:--|
| **满足赛题基础要求③** | 48kHz 采样率、ACR (N=6144) 动态时钟恢复，保留 L1 测试音可一键切回验证 |
| **解决单音合成频谱单调问题** | 纯单音正弦波在同一时刻仅含单一基频，频谱柱仅 1 根亮；改为**“主旋律 + 低音伴奏 + 基波/2次/3次泛音波表”**后，高中低频段同时具有丰富能量，8 段频谱柱律动饱满 |
| **命中赛题扩展⑤“频谱或波形显示”** | 赛题解析明确提出“生成频谱或波形显示”；增加 **640 点实时示波器声波曲线**仅耗 1 块 BRAM9K、**0 DSP**，却能呈现高帧率丝滑声波，与 8 段频谱柱形成极强的视觉冲击力 |
| **极低资源与零 SD 冲突** | 无需 SD 卡仲裁与大体量音频 FIFO，总计仅需 ~1,100 LUT + 2 块 BRAM9K + ~8 个 DSP |

## 2. L2：多谐波/双音伴奏波表音乐合成（`synth_player`）

### 2.1 架构框图

```
note_rom (主旋律 64×16 + 低音伴奏 64×16)
   ├── 主声部 (Melody)：freq_word_m ──► phase_acc_m (32bit) ──► 多谐波波表 (基波+2/3次泛音) ──► ADSR包络 ──┐
   └── 伴奏声部 (Bass) ：freq_word_b ──► phase_acc_b (32bit) ──► 三角波/正弦波生成          ──► 伴奏包络 ──┼──► 混音与音量 ──► 24-bit PCM / I2S
                                                                                                         │
                                                                                         音色选择 (timbre_sel[1:0])
```

### 2.2 核心参数与多音色设计

| 参数项 | 规格说明 |
|:--|:--|
| 采样率与时钟 | `48kHz`（由 `12.288MHz` 主时钟 `/256` 严格分频） |
| 声部结构 | **2 声部复调**：Voice 0 主旋律（C4–C6）+ Voice 1 低音分解和弦伴奏（C3–B3） |
| 多音色切换（K10 键） | `timbre=0`：富泛音管风琴/电钢琴（`sin(θ) + 0.5*sin(2θ) + 0.25*sin(3θ)`，预存入 256×16 波表）<br>`timbre=1`：柔和三角波 + 正弦伴奏<br>`timbre=2`：复古八位机方波（Chiptune 风格，奇次谐波极其丰富） |
| 包络发生器（`env_gen`） | 快速起音（Attack ≈ 5ms）+ 指数衰减（Decay/Release），彻底消除音符切换爆音（Click/Pop） |
| 曲目长度 | 64～128 拍循环乐段（如《欢乐颂》/《卡农》片段，带伴奏和弦） |

### 2.3 相位累加频率字计算

$$
\text{freq\_word} = \text{round}\left(\frac{f_{\text{note}} \times 2^{32}}{48000}\right)
$$

例如标准音 `A4 = 440Hz` $\rightarrow$ `freq_word = 39,370,534`。

## 3. 实时声波曲线 + 8 段频谱能量柱（`audio_viz`）

### 3.1 实时示波器声波曲线（Waveform）—— 零 DSP、高丝滑度
1. **双口行缓存（`wave_ram`：`640 × 8bit`，1 块 BRAM9K）**：
   - **写侧（48kHz 采样节拍）**：每个音频采样点（或每帧同步触发过零点锁相触发）将高 8 位有符号振幅映射到 `0..63` 写入 `wr_x`（`0..639`）；
   - **读侧（25MHz `video_clk`）**：根据当前视频扫描列坐标 `x` 实时读出 `wave_y = wave_ram[x]`；
2. **渲染逻辑（在 `osd_composer` 中）**：
   - 设波形显示基线 `Y_BASE = 412`；
   - 当扫描行 `y` 满足 `|y - (Y_BASE - wave_y)| <= 1` 时，渲染高亮青色波形线（`24'h00FFFF`），并在波形下方填充半透明渐变阴影。

### 3.2 8 段频谱能量柱（8-Band Spectrum Bars）
1. **频段划分**：覆盖 `130Hz ~ 2.6kHz`（精准对应 C3 低音伴奏至 C6 主旋律及 2/3 次泛音区域）；
2. **能量提取**：
   - 采用 8 路并行一阶/二阶 IIR 带通（或时分复用 Goertzel + 音符谐波能量映射），在每帧（约 800 个采样点窗口）内对绝对值 $|y_k[n]|$ 进行累加求平均能量；
3. **视觉平滑处理（Peak Hold & Gravity Decay）**：
   - 柱体高度每帧按指数平滑更新：`bar[k] <= (bar[k]*3 + energy[k]) >> 2`；
   - 顶部带白色**峰值保持游标（Peak Dot）**，以每 2 帧下降 1 像素的速度缓降；
   - 柱体颜色随高度渐变：底部翠绿（`24'h00E676`）→ 中部明黄（`24'hFFEA00`）→ 顶部火红（`24'hFF1744`）。

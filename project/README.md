## 4. 快速开始

1. 安装 **TD 5.6.5**（含 `Anlogic.lic`）；
2. 打开 `main_project.al`（v3.1 重构后）；
3. 综合 → 布局布线 → 下载；
4. TF 卡：FAT32、根目录、`01.bmp`…`04.bmp`（640×480、24bit、非压缩）；
5. HDMI 接显示器（带喇叭/音频输出）；
6. 上电：数码管显示状态，自动轮播。

> 素材制作见 `doc/素材与字库规范.md`；引脚见 `doc/引脚与硬件.md`。

---

## 5. 红线

1. **零处理器**：禁用 M0 软核、外挂 MCU；
2. **加密 IP 只黑盒**：不改 `.enc.v`；
3. **换帧只在 V-BLANK**；
4. **读口只初始化 LOAD 一次**；
5. **单 bitstream + 上电自启**；
6. **HDMI 1.4b 核必须带音频**（基础要求③）。

---

## 6. 工程约定

- 官方模块用高有效 `rst`，自研用低有效 `rst_n`；
- 视频流水线每级同时延迟 `rgb/hs/vs/de/x/y`；
- 跨域单比特 2FF，多比特 FIFO/BRAM；
- 任何接口改动先改 `doc/接口对接表.md`。
